# lib — 외부 라이브러리 래퍼

앱에서 쓰는 서드파티 연동을 `@/lib/*` 로 모아 둡니다.

| 모듈 | 패키지 / 용도 |
|------|------|
| `@/lib/store` | `zustand` — 전역 상태 |
| `@/lib/i18n` · `src/locales/` | `i18next` + `react-i18next` — 다국어 |
| `@/lib/calendar` | `@fullcalendar/react` |
| `@/lib/swiper` | `swiper` |
| `@/lib/lottie` | `lottie-react` |
| `@/lib/clipboard` | `clipboard-copy` |
| `@/lib/dnd` | `@dnd-kit/*` |
| `@/lib/viewer` | `viewerjs` |
| `@/lib/scroll` | `simplebar-react` |
| `@/hooks/useClickOutside` | 바깥 클릭 감지 |
| `@/lib/youtube` | `react-youtube` |
| `@/lib/charts` | `@amcharts/amcharts5` |
| `@/lib/dayjs` | `dayjs` |
| `@/lib/staticParams` | App Router `generateStaticParams` 헬퍼 |
| `@/lib/siteTitle` · `pageTranslate` | 문서 타이틀 · 페이지 번역 유틸 |
